# Data Mining

Repositorio del curso de Minería de Datos, donde se reúne material de ayudantías, ejercicios, desarrollos y recursos del curso. El objetivo es introducir conceptos y técnicas para extraer conocimiento útil a partir de datos, con enfoque práctico en análisis exploratorio, modelado predictivo y aprendizaje automático.

## Temas que abarca el curso

El contenido del repositorio incluye temas fundamentales de minería de datos y aprendizaje estadístico, entre los que se destacan:

- Introducción a la minería de datos y conceptos básicos.
- Preparación y limpieza de datos.
- Análisis exploratorio y manejo de variables.
- Modelos lineales y regresión logística.
- Clasificación y predicción.
- Clustering y segmentación de datos.
- Análisis de componentes principales (PCA).
- Reducción de dimensionalidad.
- Selección automática de variables.
- Resolución de ejercicios y ayudantías aplicadas.

## Estructura del repositorio

- Ayudantias/: material de las ayudantías, notebooks, scripts y archivos auxiliares.
- Desarrollo Ayudantia/: soluciones y desarrollos de los ejercicios del curso.

Este repositorio sirve como material de apoyo para estudiar, practicar y revisar los contenidos del curso de forma organizada.
